설치 안내

  
네이티브 호스트가 설치되지 않았다면, 저장소 루트에서 PowerShell로 실행하세요:

  
powershell -ExecutionPolicy Bypass -File install\install.ps1

  
설치 후 Chrome을 완전히 다시 시작하면 연결됩니다. 설정 파일: %USERPROFILE%\.devspace-gem\config.json (allowedRoots 등), 로그: %USERPROFILE%\.devspace-gem\logs\host.log.

  
HTTP 대체 경로를 쓰려면 서버를 실행한 뒤 위에서 전송 방식을 HTTP로 바꾸고 토큰을 입력하세요:

  
node server\http-server.mjs
